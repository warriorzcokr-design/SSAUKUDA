# 싸우쿠다 홈페이지

## 파일 구성
- `index.html` : 홈 (수업 안내, 수강료, 코치, 선수·시합 요약, 블로그, 오시는 길)
- `coach.html` : 코치 소개
- `records.html` : 선수·시합 기록 (시합 기록 표, 선수별 전적, 선수 카드)
- `images/` : 사진 (hero.jpg 전사 사진, coach.jpg 관장 사진)
- `dc-lite.js` : 화면 갱신용 스크립트 (고치지 않아도 됩니다)

## 깃허브에 올리기
1. 깃허브에서 새 저장소를 만듭니다. (예: ssaukuda-site)
2. 이 폴더 안의 파일과 images 폴더를 그대로 올립니다. (index.html이 맨 위에 있어야 합니다)
3. 저장소 Settings → Pages → Branch를 main / (root)로 정하고 저장합니다.
4. 몇 분 뒤 나오는 주소에서 사이트가 열리는지 확인합니다.

## teamssaukuda.com 연결 (확인을 마친 뒤)
1. 기존 워드프레스 사이트를 먼저 백업합니다.
2. Settings → Pages → Custom domain에 teamssaukuda.com을 적습니다.
3. 도메인을 산 곳(가비아 등)의 DNS 설정에서 깃허브 안내대로 A 레코드 / CNAME을 바꿉니다.
4. 연결되면 Enforce HTTPS를 켭니다.

## 시합 기록 추가하기
`records.html`에서 `id="match-table"` 표 안의 `[날짜]`, `[선수 이름]` 같은 빈 줄을 채우면 됩니다.
선수 수, 경기 수, 승률, 선수 카드, 홈의 숫자는 자동으로 다시 계산됩니다.

이적 선수 명단은 `records.html` 맨 아래 스크립트의 `"transferred": "서지훈, 설주영, 김민재"` 부분을 고치면 됩니다.

## 올리기 전에 채우면 좋은 것
- 카카오톡 문의 버튼 → 카카오톡 채널 링크
- 오시는 길 → 네이버/카카오 지도 퍼가기 코드
- 선수 사진, 체급, 상해보험 안내, 코치 대회·시상 사진
